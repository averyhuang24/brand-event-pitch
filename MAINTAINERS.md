# Maintainers

## Release Checklist

When publishing an update:

1. Update `brand-event-pitch/VERSION`.
2. Add notes to `CHANGELOG.md`.
3. Commit and push to `main`.
4. Create a GitHub Release with a tag matching the version, such as `v0.2.1`.
5. Tell users to watch **Releases** on GitHub if they want update notifications.

The skill itself does not auto-update on users' machines. Users manually pull or download the latest version and copy `brand-event-pitch/` into their agent skills directory.
