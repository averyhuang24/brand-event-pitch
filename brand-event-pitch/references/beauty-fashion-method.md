# Beauty & Fashion 招商 Method

Use this reference when the user works on beauty, skincare, personal care, apparel, fashion, styling, new-season launch, trend report, creator inspiration, or large-style-category招商.

## Core Industry Logic

Beauty and fashion are not sold only by exposure. They are sold through:

- **Trend definition**: the brand wants to become the representative of a style, season, product effect, or aesthetic keyword.
- **Suitability solving**: users care whether this look/product fits their face, body, skin, style, occasion, budget, or identity.
- **Visual desire**: image, mood, texture, people, product closeups, outfit/makeup looks, and scene matter as much as copy.
- **Proof-to-conversion loop**: trend content must connect to search, live, store/shelf, product list, ranking, coupon, or offline try-on.

Default question: **What style problem or beauty/fashion desire can this campaign help users solve, and which brand can own that answer?**

## Key User Questions

Beauty users ask:

- What effect does it create: glow, matte, clean, soft, repaired, bright, firm, fragrant, fresh?
- Does it fit my skin, season, makeup skill, occasion, and budget?
- Is it trusted: ingredient, efficacy, creator review, expert proof, ranking, before/after?
- Can I copy the look easily?

Fashion users ask:

- Does it fit my body shape, height, commute, date, travel, office, campus, sports, or social occasion?
- What item should I buy to complete the look?
- How do I style it without looking awkward?
- Is this trend already socially legible enough to wear?

招商 implication: Do not only sell products. Sell **solutions to self-presentation problems**.

## Campaign Packaging Formulas

### 1. Trend Ownership

Best for: seasonal launches, apparel collections, makeup trends, category refresh.

Structure:

1. Name 5-6 trend tracks.
2. Define the look/effect in one sentence.
3. Show visual examples and key items/products.
4. Provide creator demonstration and user participation mechanism.
5. Sell limited brand slots by trend track.

Sellable rights:

- trend naming partner
- track title sponsorship
- product inclusion in trend guide
- creator styling/makeup demo package
- search/store/listing handoff
- trend report and PR quote

### 2. Treasure List / Ranking

Best for: beauty products, seasonal newness, top items, gift sets, creator recommendations.

Structure:

1. Build an editorial-style list: "seasonal treasure", "must-have", "trend pick", "problem-solving list".
2. Use strong visuals: model look, product matrix, mini review, ranking number.
3. Connect each product to a user need or effect.
4. Add creator seeding and live/store conversion.

Sellable rights:

-榜单入选/共创名额
- category ranking package
- product detail page / search / store module
- short video review matrix
- live-room "list day"
- post-campaign ranking report

### 3. Style / Beauty Lab

Best for: professionalizing a campaign and making it feel less like ordinary达人种草.

Structure:

1. Define a public problem: "how to dress effectively", "how to find my spring makeup", "how to repair after summer sun".
2. Build a lab mechanism: diagnosis, test, challenge, expert/creator panel, result card.
3. Let users participate by submitting face/skin/style/occasion scenarios or choosing a route.
4. Let brands enter as solution providers.

Sellable rights:

- lab co-builder
- expert/creator testing slot
- diagnosis card brand recommendation
- before/after content
- offline try-on / makeover / sampling station
- asset library after the campaign

### 4. Scene Route / Occasion Map

Best for: apparel, fragrance, body care, travel/outdoor, city retail, new store/mall campaigns.

Structure:

1. Define a set of occasions: commute, date, office, campus, workout, citywalk, party, travel, beach, festival.
2. Pair each scene with a look/product solution.
3. Build route map, challenge, creator itinerary, offline check-in, or live shopping day.
4. Sell brand ownership of scenes.

Sellable rights:

- scene ownership
- route/map placement
- offline check-in point
- creator lookbook/video
- live/store handoff by scene
- city/street/mall extension

## Useful IP Directions

Use these as starting points, then adapt to the user's node and brand category:

- **Seasonal Trend Release**: platform publishes seasonal style/beauty trends and sells track ownership.
- **Treasure List / Beauty-Fashion Awards**: editorial ranking plus creator proof and store conversion.
- **Effective Styling Clinic**: solve body/occasion problems with creators, stylists, and product bundles.
- **Makeup Effect Lab**: pair trending makeup effects with product categories and creator tutorials.
- **New-Season Try-On Week**: offline fitting/makeup stations plus live and short-video conversion.
- **Occasion Wardrobe / Occasion Beauty Map**: every occasion gets a look and a brand solution.
- **Creator Lookbook Relay**: creators pass one trend/theme across categories and cities.
- **Texture Museum**: tactile/visual category campaign for skincare, fragrance, fabric, color, shine, matte, sheer, airy, structured.

## Page / Section Modules

For PPT:

- trend summary visual: 5-6 looks/effects in one page
- user problem page: "why users cannot easily choose"
- look/effect page: large model/product image + 3 proof points
- item/product matrix: core items, substitutes, price bands, category roles
- creator proof page: tutorials, before/after, UGC, expert comments
- conversion page: search/live/store/list/offline path
- brand package page: trend ownership, list inclusion, creator package, event package

For proposal documents:

- opening callout must name the trend/IP and the commercial package
- trend tracks should be tabled: track name, user need, visual cue, category fit, brand role
- each gameplay should include user action, creator action, brand action, platform/channel resource, deliverable
- include a "brand can own what" section

## Visual Rules

Beauty/fashion招商 materials must be image-led:

- Use large model/look/product/texture images.
- Product grids and ranking layouts work well for beauty.
- Outfit boards, street snaps, item matrices, and occasion maps work well for fashion.
- Avoid generic fashion stock if it does not show the actual trend, item, or scene.
- Use closeups for texture/effect: lips, skin, hair, fabric, shine, matte, sheer, structure.
- Use full-body or half-body imagery for silhouette, proportion, and occasion.
- If no image assets exist, proactively source public theme images or generate placeholders based on exact visual brief.

## Commercialization Checklist

Before presenting an idea, ensure it has:

- trend or problem name
- user participation reason
- creator demonstration role
- brand category fit
- sellable scarcity: limited tracks, ranking spots, scene ownership, lab partner, list partner
- resource package: hard ads, short film, creator matrix, live, store/search, offline event, PR/report
- conversion handoff: search/live/store/coupon/offline
- post-campaign asset: report, ranking, lookbook, case video, creator clips

## Common Mistakes

- Selling "fashion exposure" instead of a trend ownership position.
- Using beautiful images without proving a user problem or commercial role.
- Naming trends that do not connect to products.
- Treating beauty as only makeup and ignoring skincare, fragrance, body care, tools, repair, texture, and efficacy.
- Treating fashion as only clothing and ignoring body shape, occasion, styling method, accessories, fabric, and confidence.
- Creating an event that looks exciting but has no store/search/live handoff.
