# Slide Chrome And Contact Rules

招商 decks often use small page chrome, but chrome must never invent identity. Do not auto-fill organizer, platform, department, author, phone, email, confidentiality, or source labels.

## Hard Rules

- Do not put text in the top-left corner by default.
- Do not add a persistent header, runner, footer, department label, platform label, or source label unless the user explicitly provides the wording.
- Do not write generic or invented labels such as "招商方案", "Marketing Center", "Brand Team", "Campaign IP Center", "Confidential", "Internal", or any platform/department name.
- Do not add a responsible person's name, title, phone number, email, QR code, or contact block unless the user explicitly provides it and asks to include it.
- The final slide should usually say only a simple closing line such as "期待合作" / "Thank You" / "Let's Build This Moment", plus an optional visual. No contact details by default.
- If a bundled template specifies runner/footer/chrome text, use the layout style only and remove or blank the text.
- Page numbers are allowed only if they are subtle and do not create a visible title-like label.
- Logos are allowed only when provided by the user or when the user explicitly asks for a placeholder logo area.

## Allowed Chrome

These are acceptable when useful and unobtrusive:

- tiny page number
- small section marker, e.g. "01 / Opportunity"
- abstract graphic mark without words
- user-provided logo
- user-provided event name, only where it supports navigation

Do not place allowed chrome in the top-left if the user says the top-left should be blank.

## Closing Slide

Default closing slide:

- large atmospheric visual or clean brand/event mood
- one short line: "期待合作" or equivalent
- no person name
- no email
- no phone
- no QR code
- no invented organization name

Only add contact information if the user provides exact text such as:

```text
Contact: Name, title, email, phone
```

## Review Checklist

Before delivery, inspect visible text across all slides:

- top-left corners are blank unless explicitly approved
- no invented organization or department names
- no accidental template runner/footer strings
- no invented contact details
- closing slide has no name/email unless requested
