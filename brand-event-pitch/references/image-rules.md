# Image-Led 招商 Deck Rules

优秀招商 PPT 通常是图像先行、文字克制：大图建立活动世界观，少量文字完成判断、承诺和招商解释。不要把招商方案做成“文字报告换了个模板”。

## Non-Negotiable Rules

- A designed招商 deck must not be text-only.
- At least 60% of non-table slides should contain theme-relevant imagery, collage, mockup, map, UI screenshot, product/category image, or event scene.
- Opening 3 slides must include at least one strong visual scene or campaign-world image.
- Hero/concept pages should usually have 50-80% visual area.
- Text should be a claim, label, number, or annotation; avoid long paragraphs over large images.
- If real images are unavailable, use generated campaign visuals, public/sourceable images, or clearly marked placeholders. Do not silently omit images.

## Image Roles

Use images to do one of these jobs:

- **World-building**: show the atmosphere of the campaign, event, season, city, crowd, category, or cultural moment.
- **Proof**: show real product, real people, real location, real usage, screenshot, data visual, or media-style evidence.
- **Mechanism**: show how users participate: route map, challenge card, live-room frame, creator content grid, stage/event layout.
- **Brand entry**: show where a brand appears: booth, package, product moment, creator scene, live set, shelf/store module.
- **Desire**: make the opportunity feel worth joining, not merely understandable.

## Image Plan Template

Before final deck generation, create a compact image plan:

```text
P1 Cover: hero campaign visual, source: generated/public/user asset, role: world-building
P2 Opportunity: consumer scene collage, source: public/generated, role: prove cultural moment
P3 Platform/channel proof: UI/content grid mockup, source: generated mockup, role: mechanism
P4 Big Idea: full-bleed visual metaphor, source: generated, role: concept
...
```

If a page does not need imagery, state why. Tables, package matrices, and detailed roadmaps may be mostly text/data, but should still use visual hierarchy.

## Sourcing Guidance

Prefer sources in this order:

1. User-provided images, logos, KV, product shots, event photos, screenshots, sample deck images.
2. Public images that clearly match the campaign theme and can be attributed if needed.
3. Generated visuals based on the campaign theme.
4. Abstract but theme-specific graphics: route maps, UI mockups, event layouts, product/category silhouettes.
5. Placeholders only when the agent cannot access images; label them as assets to replace.

When using public or generated images, keep them generic enough for the public repository and avoid implying endorsement from real people, brands, or platforms unless the user provided those assets.

## Page-Type Image Expectations

- Cover: full-bleed hero image or high-impact campaign collage.
- Insight: real-world consumer/culture/category scene plus one sharp claim.
- Platform/channel proof: content grid, UI journey, creator matrix, live/search/store mockup.
- Big Idea: visual metaphor or campaign key visual.
- Mechanism: illustrated flow, map, content cards, or scene-by-scene storyboard.
- Brand role: product-in-scene mockups or brand touchpoint examples.
- Resource matrix: mostly table, but include icon system, resource thumbnails, or layout mockups.
- Roadmap: timeline with phase imagery or campaign material thumbnails.
- Package: clean table; imagery optional but use visual tags/icons.
- Closing: campaign atmosphere or partnership invitation visual.

## Failure Modes

Avoid these:

- text-heavy slides with decorative background only
- generic stock images that could fit any deck
- one image repeated across the whole deck without a reason
- screenshots or mockups too small to read
- image collages with no hierarchy
- beautiful visuals that do not prove the招商 point
