# Live Trend Research Workflow

Use this reference whenever the user asks for招商营销点子、活动创意、campaign IP directions, hot-content-inspired ideas, or gives a theme/category/node and asks for brain-storming. Trend research is the default first step unless the user explicitly says not to search, the task is only packaging a fixed existing idea, or the user only asks for an internal-framework answer.

The goal is not to list hot topics. The goal is to find live social content signals, extract repeatable mechanisms, and convert them into brand-sellable招商 ideas.

## Capability Rule

Before claiming current platform insight, identify the available source route:

- **platform-native**: a Xiaohongshu/RedNote or Douyin MCP/plugin/connector can search posts/videos, rankings, keywords, comments, engagement, or creator examples directly.
- **web-indexed**: only public web search, platform pages indexed by search engines, media reports, creator articles, or third-party summaries are available.
- **user-provided**: user supplied links, screenshots, exported notes, topic-meeting notes, or pasted content.

If only web-indexed sources are available, say the research is a public-web approximation, not a complete in-app trend scan. Do not pretend to have accessed Xiaohongshu or Douyin native search.

If platform-native MCPs are not enabled, do not stop. State the missing capability, use web-indexed search if available, and tell the user that enabling the optional Trend MCP Pack will improve Xiaohongshu/Douyin coverage. If the user wants this capability installed or bundled for non-technical teammates, read `../integrations/trend-mcp-pack.md`. The default trend layer is read-only: search, detail, comments, transcript, and metadata only.

## Search Plan

Build 6-10 searches around the user's theme. Mix these dimensions:

1. **Theme keywords**: category, node, occasion, user group, product, pain point.
2. **Platform keywords**: 小红书, 抖音, 红书, Douyin, RedNote.
3. **Trend words**: 爆火, 最近, 热门, 跟风, 挑战, 话题, 模板, 妆容, 穿搭, 直播, 翻拍, AI, 测评, 榜单.
4. **Commercial words**: 种草, 带货, 直播间, 开箱, 测评, 试用, 好物, 榜单, 快闪, 品牌.
5. **Behavior words**: 打卡, 改造, 跟练, 仿妆, 翻包, 一日体验, 挑战, 测试, 交换, 投票, 排名.

For beauty/fashion, include style/effect terms such as 妆容、色彩、肤质、成分、穿搭、体型、OOTD、风格测试、有效穿搭、春夏、秋冬、通勤、约会、户外、松弛感.

## What To Collect

For each useful trend signal, capture:

- source route: platform-native / web-indexed / user-provided
- platform and link if available
- keyword/query used
- content format: short video, note, livestream, challenge, list, test, offline event, creator format, meme, AI tool, product demo
- watch reason: why people care
- repeatable mechanism: what can become episodes or user participation
- user action: watch, submit, test, vote, remix, buy, search, visit, screenshot, share
- brand role: product proof, scene builder, task sponsor, list sponsor, expert answer, prize, route stop, makeover tool, challenge owner
- evidence strength: strong / medium / weak

Do not over-index on one viral meme. Prefer patterns repeated across multiple creators, comments, formats, or platforms.

## Filtering Rules

Keep a trend only if at least two of these are true:

- It has a clear human tension or practical problem.
- It has a repeatable content engine, not just a one-time joke.
- Users can participate or imitate it.
- Brands can enter naturally without looking like a hard ad.
- It can connect to search, live, store/shelf, coupon, offline event, PR, or a report.
- It can create memorable short-video/live moments.

Discard or downgrade:

- Pure slang with no action.
- Controversial, unsafe, illegal, discriminatory, or platform-risky topics.
- Trends that rely on copyrighted show formats without meaningful transformation.
- Topics where brand entry would only be logo exposure.

## Conversion Steps

After research, convert sources into招商 ideas in this order:

1. Cluster signals by content mechanism, not by keyword.
2. Name each cluster's watch reason.
3. Translate the mechanism into an event/IP system.
4. Add brand roles and sellable rights.
5. Add conversion/asset handoff.
6. Only then create the campaign name.

## If MCP Is Missing

If the environment lacks Xiaohongshu/Douyin MCPs and live web results are weak, ask for one of:

- 5-20 Xiaohongshu/Douyin links around the theme
- screenshot pack of search results, hot notes, comments, or creator videos
- weekly topic meeting notes
- exported creator/video list with titles and links

Then proceed with user-provided analysis using `content-trend-method.md`.
