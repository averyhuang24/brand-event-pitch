# 品牌招商 PPT 方法论

## 核心判断

招商 PPT 的任务不是完整介绍活动，而是降低品牌决策风险。品牌方关心三件事：

- 值不值得投：这个节点是否有足够大的人群、情绪、内容和交易机会。
- 投进去做什么：品牌能以什么角色进入，而不是只买曝光位。
- 投了有什么确定性：资源、节奏、交付物、权益、转化路径是否清楚。

## 故事线公式

### A. 大促/节点型

适合大促节点、年货节、赛事节点、暑期消费季、会员日、行业消费季。

结构：

1. 消费者在这个节点的决策方式变了。
2. 平台或渠道上已经出现可被放大的内容、搜索、互动或购买行为。
3. 平台把分散行为包装成一个可参与的事件。
4. 品牌通过内容、达人、直播、货架、搜索、PR 进入不同阶段。
5. 合作权益和资源保证品牌不只是蹭热度，而是获得节点中的确定位置。

高频页面：

- 节点消费洞察
- 用户内容行为/平台数据
- 活动主题和 Big Idea
- 三阶段 Roadmap
- 品牌玩法与资源矩阵
- 品类合作方式
- 权益包/招商席位

### B. 平台 IP/情绪趋势型

适合“夏天怎么过”“源头好货”“毕业季”“城市派对”等。

结构：

1. 找到一个全民可感知的情绪或生活方式。
2. 用平台内容生态或社交行为证明它已经在发生。
3. 平台给它命名并放大成 IP。
4. IP 被拆成多个可传播、可打卡、可交易的副本/赛道。
5. 品牌认领其中一个情绪、场景或消费理由。

高频页面：

- 情绪洞察
- 热点话题/UGC 证明
- 主题命名
- 赛道/副本地图
- 达人/KOL 追风
- 品牌共创玩法
- 线下现场/直播间/货架联动

### C. 内容栏目/综艺植入型

适合明星、达人、团综、赛事陪看、直播栏目。

结构：

1. 证明内容 IP 已经有观看理由或粉丝基础。
2. 提炼内容升级点和商业特色。
3. 把品牌植入从“露出”变成剧情、任务、道具、人设或互动。
4. 给出内容产出、传播矩阵和可合作品类。
5. 明确合作形式和权益。

高频页面：

- IP 成绩/粉丝反馈
- 第二季/新栏目升级
- 人设或嘉宾价值
- 内容环节设计
- 品牌自然植入示例
- 传播玩法和平台矩阵
- 可合作品类/权益

### D. 电商/消费节点型

适合 618、双 11、年货节、开学季、季节消费、品类日、货品趋势和商城项目。

结构：

1. 证明节点里用户需求或消费决策正在变化。
2. 证明平台能把内容兴趣导向交易场景。
3. 把活动主题包装成一个可被用户参与、达人讲述、商家承接的消费理由。
4. 拆出内容种草、直播爆发、搜索承接、货架/主会场转化。
5. 给出品牌在不同档位下能拿到的生意资源和内容资产。

高频页面：

- 消费趋势/品类趋势
- 节点机会与用户需求
- 平台内容到生意链路
- 活动主题和消费主张
- 达人/明星/直播/店播玩法
- 搜索、主会场、货架承接
- 合作席位、资源包、锁单/下单规则

### E. 线下/城市事件型

适合市集、音乐节、城市漫游、快闪、展会、赛事现场、颁奖礼。

结构：

1. 证明线下场景有天然情绪、人群或社交传播价值。
2. 说明平台如何把线下热闹放大到线上内容和交易。
3. 把活动拆成可打卡、可直播、可种草、可转化的场景。
4. 给品牌清楚的现场角色：展位、装置、互动、试用、内容共创、直播承接。
5. 用线上资源和战报证明线下投入不会停留在现场曝光。

高频页面：

- 城市/场景/节日情绪洞察
- 线下活动信息与场次排期
- 市集/快闪/展位/装置地图
- 明星达人探访或直播
- 线上话题、H5、主会场、货架承接
- 品牌现场权益与物料需求
- 现场到线上传播 Roadmap

### F. 本地生活/城市生意型

适合生活服务、城市营销、商圈快闪、文旅联动、NKA 零售、餐饮酒旅、洗浴休闲、赛事城市生活等。

结构：

1. 先证明城市、商圈、门店或生活场景里有真实消费动机，不要只讲平台流量。
2. 用一个城市标签或生活方式命名把分散门店和商家组织成事件。
3. 把线上氛围、达人陪逛、明星到店、线下快闪、门店交易和平台资源串成闭环。
4. 按品类/商圈/门店类型拆品牌角色：谁适合做主会场、谁适合做门店任务、谁适合做快闪体验。
5. 明确本地生活项目的成交定义：到店核销、套餐售卖、直播预约、门店引流、商家联合资源，而不只写曝光。

高频页面：

- 城市/商圈/门店消费洞察
- 城市标签或生活方式主题
- 明星/达人陪逛或一日店长
- 线下商圈快闪/NPC/地标事件
- 品类赛道特色玩法
- 门店/商家联合权益
- 到店交易、直播预约、主会场和渠道承接
- 项目下单定义和招商对接人

### G. AI/技术内容型

适合 AI 创作大赛、AIGC 内容、技术互动产品、品牌定制 AI 内容。

结构：

1. 证明技术正在改变内容生产、用户表达或品牌素材效率。
2. 说明平台已有创作者、内容分发和案例积累。
3. 把技术趋势变成可参与的赛道、征稿、挑战或共创机制。
4. 给品牌从广告主升级为共创者、出题方、赛道伙伴或内容资产拥有者的角色。
5. 用作者供给、评审背书、素材沉淀和传播资源降低品牌尝试新技术的风险。

高频页面：

- 技术趋势与内容形态变化
- AI 创作者生态和优质内容数据
- 赛制/赛道/征稿机制
- 品牌定制赛道或出题机制
- AI 短片、贴纸、互动产品、创作者沙龙
- 评审/导演/专家背书
- 素材资产和 PR 战报沉淀

新增样本显示，AI/技术内容型如果只讲“AI 很新”会显得空。更有效的写法是把技术议题赛事化：

- 经典回归/行业命题：先借一个大众能理解的旧问题，如广告、审美、创意效率。
- 全民参与/爆改机制：让用户或创作者有明确作品产出。
- 专业评审/线下盛典：用评审、大奖、作品展或盛典建立可信度。
- 品牌定制赛题：品牌不是赞助商，而是出题方、素材方、命题方或最佳实践样本。
- 素材复用：把参赛作品、创意模板、案例 PR 和品牌资产沉淀为可二次使用的内容库。

### H. 兴趣组局/圈层直播型

适合达人兴趣直播局、朋友局、运动/户外/宠物/读书/手串/游戏等圈层项目。

结构：

1. 先证明“同一个兴趣”能自然形成关系、身份和消费理由。
2. 让明星或达人从带货者变成兴趣主理人、局长、队长、店长或探展团成员。
3. 把直播间或线下现场写成一场“局”，而不是一场直播。
4. 内容前段负责种草和人设，直播/现场负责互动和成交，短视频切片负责长尾。
5. 品牌进入方式必须贴着兴趣动作：装备、穿搭、补给、道具、陪伴、任务、榜单、奖品、探展路线。

高频页面：

- 圈层情绪/兴趣关系洞察
- 兴趣主理人或达人阵容
- 组局机制和场次规划
- 沉浸式直播或线下局
- 直播热点切片和短视频二创
- 品类角色与品牌自然植入
- 圈层资源包与持续场次预告

## 招商营销点子生成

当用户要“想招商方案的营销点子”“活动创意”“品牌合作玩法”时，先生成可招商的活动机制，再进入 PPT 或文档写作。点子的目标不是新奇，而是能被销售卖出去、被品牌自然买入、被项目组执行。

一个合格点子必须同时成立六件事：

1. **用户有参与理由**：拍、看、搜、买、打卡、投稿、投票、共创、到场中的至少一种行为足够自然。
2. **品牌有自然角色**：品牌不是贴 logo，而是提供道具、任务、场景、福利、内容命题、商品承接或身份背书。
3. **平台资源能放大**：达人、话题、直播、搜索、货架、H5、线下、PR、战报中的资源路径清楚。
4. **权益可售卖**：能拆出冠名、行业合作、品类伙伴、定制赛道、联合 KV、资源包、席位、排他或素材授权。
5. **执行节奏可落地**：至少能分成预热、爆发、长尾，或清楚说明单场/多场执行。
6. **成果可复盘**：曝光、互动、内容资产、直播引流、搜索承接、转化、线下到场、PR、战报等结果有口径。

发想时优先用“节点机会 + 用户动作 + 品牌角色 + 资源闭环”组合，而不是先起名字。

可复用创意母题：

- **任务型**：用户完成挑战/打卡/投稿，品牌提供任务命题、奖品、商品或场景。
- **赛道型**：把一个大主题拆成多个品类赛道，品牌认领其中一个赛道。
- **榜单型**：用达人、商品、城市、场景或内容榜单制造可传播结果。
- **共创型**：用户/达人/品牌一起产出内容、海报、短片、AI 素材或线下装置。
- **体验型**：把商品卖点变成线下快闪、市集、试用、路线、展位或直播间体验。
- **证明型**：围绕真实、源头、成分、科技、测评、专家背书建立信任。
- **转化型**：内容种草后接搜索、直播、主会场、货架、店播或官旗承接。
- **资产型**：让品牌获得可复用的 IP 授权、联合 KV、达人素材、战报案例或 PR 话题。

输出营销点子时，每个方向使用以下结构：

```text
点子名称：
一句话概念：
适合品牌：
用户为什么参与：
核心玩法：
品牌怎么进入：
可卖权益：
资源闭环：
执行节奏：
风险/待确认：
```

不要把这些内容当作点子本身：

- “做一个话题挑战”
- “找达人种草”
- “品牌露出”
- “直播带货”
- “线下快闪”
- “发 PR 稿”

这些只是资源或动作。必须继续追问：用户为什么参与、品牌以什么身份进入、资源如何组成闭环、最终卖什么权益。

## 页面写法规则

- 每页只承担一个决策功能：证明、命名、解释、承诺、成交。
- 标题要下判断，不要只做分类。例如用“用户不再只为低价下单，而是为看得见的真实买单”，不要用“用户洞察”。
- 数据后必须接解释：这个数字改变品牌的什么决策。
- 玩法页必须包含四件事：用户动作、品牌动作、平台资源、产出结果。
- Roadmap 不只是时间轴，必须显示每阶段的营销任务：预热蓄水、爆发转化、长尾沉淀。
- 权益页必须能被销售直接拿去谈：资源项、数量/频次、席位、排他性、交付物。
- 招商手册或飞书文档转 deck 时，不要丢掉锁单/下单/活动管控信息；可压缩成“合作流程与确定性”页面。
- 如果样本附件是图片型 PDF/PPT，只学习视觉节奏和页型，不从附件中臆测正文逻辑。

## 品牌入口模块

生成方案时，根据项目类型选择品牌入口，而不是统一写“品牌露出”：

- 内容入口：达人矩阵、明星内容、官方话题、短片、征稿、大赛、榜单、PR。
- 互动入口：H5、AI 特效、贴纸、投票、打卡、挑战赛、用户共创。
- 转化入口：直播间、店播、官旗、主会场、货架、搜索组件。
- 线下入口：市集、快闪、展位、装置、沙龙、颁奖礼、城市事件。
- 本地入口：商圈主会场、门店任务、团购套餐、预约、核销、商家页、文旅/商圈联合资源。
- 圈层入口：兴趣主理人、局长/队长、装备清单、探展路线、组局任务、榜单奖品、直播切片。
- 资产入口：IP 授权、联合 KV、品牌定制海报、素材授权、战报案例。

每个入口必须回答：用户为什么参与、品牌在其中做什么、平台给什么资源、活动后留下什么资产。

## 品牌招商的必备商业语言

优先使用这些价值词：

- 内容种草
- 信任建立
- 节点转化
- 货架/门店/渠道承接
- 搜索承接
- 直播爆发
- 达人矩阵
- 品类心智
- 新品首发
- 用户共创
- 官方背书
- PR 定调
- 战报沉淀

谨慎使用这些空泛词，除非已经被具体机制支撑：

- 赋能
- 引爆
- 破圈
- 声量
- 全域
- 品效合一
- 年轻化

## 审稿问题

用这些问题判断一份招商 PPT 是否成立：

- 如果删掉平台 logo，这个方案是否仍能体现该平台/活动方的独特能力？
- 如果删掉品牌 logo，品牌是否仍能看出自己该怎么参与？
- 用户为什么愿意拍、看、搜、买？
- 达人为什么愿意讲？
- 品牌为什么现在必须买？
- 活动结束后，品牌留下什么资产？
- 权益表是否能支撑报价？
