# 样本学习结论

基于多份品牌招商方案的第一轮学习。文字可解析样本用于故事线，图片型 PDF 用作后续视觉参考。发布版只保留抽象方法，不暴露原始样本文件。

## 样本分工

- 大事件招商样本：适合学习平台型营销活动招商。页序显示资源、直播、AI 互动、搜索、主会场、达人带货等商业组件。
- 信任命题样本：适合学习消费节点中的信任命题。故事线从“用户厌倦营销话术”转到“真实源头/好物检验/追溯官”。
- 情绪趋势 IP 样本：最适合学习情绪趋势 IP。通过“造风、追风、跟风”把情绪拆成赛道、任务、现场和品牌共创。
- 城市大事件样本：适合学习大事件全链路招商：趋势洞察、主题命名、线上线下、明星达人、直播转化、品牌展位。
- 年轻人情绪样本：适合学习人群情绪和反常规 Big Idea。典型逻辑是把目标人群从观众改写为主角。
- 赛事 IP 样本：适合学习赛事 IP 的阶段命名和人群分层，用一套核心意象串联预热、爆发、长尾。
- 内容综艺样本：适合学习内容 IP 的商业植入，把品牌变成道具、任务、人设和互动。
- 轻量栏目样本：适合学习快速合作提案，结构短，重点是形式、嘉宾、内容权益和品牌植入。
- 图片型样本：可学习视觉节奏、封面气质、页内信息密度，文字需视觉拆解。
- 招商手册型样本：适合学习飞书文档/文档版方案。通常先给招商信息速览、项目编号/状态、席位价格、资源包，再展开背景、亮点、玩法、品牌权益和执行节奏。

## 共同结构

优秀招商方案通常不是从资源开始，而是按这个顺序推进：

1. 先证明一个社会情绪、用户行为或节点机会已经存在。
2. 再证明平台或活动方能把它放大成内容、互动和交易。
3. 再给这个机会一个可传播的名字。
4. 再拆成用户愿意参与的玩法。
5. 再告诉品牌可以在哪些场景进入。
6. 最后给资源、权益、时间和席位。

## 批量飞书招商手册学习结论

基于一批飞书文档形态的招商手册样本，去重后有效样本超过一百份，覆盖电商/消费节点、达人/星图 IP、内容/演出 IP、线下/城市事件、AI/技术内容等类型。样本共同特征是：正文比附件更可学习，附件多为 PDF、视频或整页图片型 PPT，适合补充视觉节奏，不适合作为主要文本来源。

这批样本说明：飞书招商手册的核心不是“完整介绍项目”，而是把销售可转发、品牌可判断、项目组可执行的信息放在一个闭环里。高频结构为：

1. 合作速览/项目重点信息/招商信息速览。
2. 项目背景或洞察。
3. 项目定位、主题或概述。
4. 项目亮点。
5. 项目玩法、内容规划或核心机制。
6. Roadmap/项目节奏。
7. 招商规划、席位、权益和资源包。
8. 锁单、下单、招商对接、活动管控规范。

高频章节不是装饰性目录，而是决策功能：

- **合作速览**：让销售和品牌先判断是否值得继续看。
- **项目背景/洞察**：回答为什么现在有机会。
- **项目亮点**：把活动资源翻译成品牌可买的理由。
- **核心玩法**：说明用户、达人、品牌和平台资源如何互动。
- **招商规划/招商权益**：支撑报价、席位和资源谈判。
- **锁单/下单流程**：把意向推进到真实成交，不能省略。
- **活动管控规范**：处理素材、审核、排期、下单口径等执行风险。

## 项目类型差异

不同类型样本的开场逻辑明显不同：

- **电商/消费节点**：从消费趋势、品类机会、节点流量和转化承接进入，必须补足直播、货架、主会场、搜索和店播/官旗承接。
- **达人/星图 IP**：从内容人群、达人供给、种草信任和创作者资源进入，重点证明品牌为什么能借达人内容建立心智。
- **内容/演出 IP**：从内容 IP、粉丝情绪、现场感、嘉宾/明星和传播场景进入，品牌要成为内容体验的一部分。
- **线下/城市事件**：从城市、场景、打卡、快闪、直播和线上货架联动进入，必须解释线下热闹如何回到线上生意。
- **AI/技术内容 IP**：从技术趋势、创作门槛变化和内容资产效率进入，品牌价值是抢占新内容语境、共创赛道和沉淀素材资产。

## 品牌入口模块库

批量样本中的品牌入口高度模块化。后续生成方案时应按项目类型选择组合，不要只写“品牌露出”：

- 达人矩阵/星图商单/精选达人团。
- 明星短视频、明星直播、明星进播或活动嘉宾。
- 官方话题、商业子话题、挑战赛、征稿、大赛赛道。
- 直播间、店播、官旗、主会场、货架/商城承接。
- 搜索组件、搜索阿拉丁、多词优选、品牌蓝词。
- H5/活动会场/互动产品/AI 特效/贴纸/榜单。
- 线下市集、快闪、展位、装置、打卡、沙龙、颁奖礼。
- PR 稿件、媒体矩阵、官方账号共创、收官战报。
- IP 授权、联合 KV、品牌定制海报、素材授权。

每个入口都要写清楚四件事：用户看见什么、品牌做什么、平台给什么资源、最后沉淀什么结果。

## 附件学习规则

飞书文档里的 PDF/PPT 附件常见三类：

- **客户版资源包**：多为资源和权益明细，优先用于校准权益字段，不作为故事线主来源。
- **图片型 PDF/PPT**：适合学习封面气质、整页大图、信息密度、权益表和 Roadmap 版式；若无可抽文字，不强行总结正文。
- **视频/素材附件**：只记录为内容证明或传播素材，不进入方法论，除非用户明确要求审看素材。

附件无法读取或下载失败时，不应阻塞正文学习；只在覆盖摘要里标明“附件未读/只做视觉参考”。

## 招商手册型文档结构

招商手册和招商 PPT 的节奏不同。手册常用于销售流转、客户细读和内部执行，因此会把关键信息前置：

1. 招商信息速览：项目定位、周期、开放行业、席位、金额、截止时间、资源包。
2. 项目背景：为什么这个节点/人群/场景有机会。
3. 项目介绍：主题、传播主张、项目策略、项目周期、活动地点或平台阵地。
4. 核心亮点：用 3-5 个亮点解释合作价值。
5. 内容玩法：逐项展开玩法，每项说明用户动作、品牌介入、资源支持和产出物。
6. 品牌权益：每个玩法后直接写品牌可获得什么。
7. 资源与席位：表格化展示合作档位、价格、席位、权益。
8. Roadmap：预热、爆发、长尾和交付节奏。
9. 注意事项：招商截止、执行条件、素材需求、bycase 审核等。

从 PPT 转手册时，不要逐页照搬。要把 PPT 的视觉页和短标题扩写成“背景解释 + 玩法说明 + 权益表格 + 执行信息”。

## 高价值叙事手法

- **反常规定义**：不是“做给目标人群看”，而是“让目标人群成为主角”。这类句式能让普通活动变成有态度的 IP。
- **用户质疑转品牌机会**：源头好货把“用户不信营销话术”转成品牌展示真实的机会。
- **动词系统**：夏日营销用“造风、追风、跟风”统一策略、内容和现场，不靠散点玩法堆砌。
- **阶段命名**：用同一套核心意象串联预热、爆发、长尾，让活动更像完整叙事。
- **场景化转化**：把行业事件从“看产品”改写成“体验生活方式”，为品牌提供真实使用场景。
- **品牌自然进入**：通过人设、道具、任务和互动让品牌成为内容的一部分，而不是贴片。

## 平台型招商迁移规则

把这些样本迁移到平台型品牌招商时，必须补上商业闭环：

- 内容热度如何导向搜索。
- 搜索如何导向品牌/商品/会场。
- 直播间在什么时候爆发。
- 货架和主会场如何承接。
- 达人内容如何变成可复用资产。
- 官方资源如何给品牌背书。
- 战报如何让品牌内部复盘时有成果可讲。

## 推荐默认页序

适合 15-20 页营销活动品牌招商方案：

1. 封面：活动名 + 招商方案。
2. 节点机会：为什么现在用户有新需求。
3. 平台/渠道洞察：这个需求如何表现为内容、搜索、互动或购买。
4. 品牌痛点：品牌在这个节点最难解决什么。
5. Big Idea：平台如何重新定义这个节点。
6. 活动总览：一句话机制 + 三阶段结构。
7. 用户参与机制：用户如何看、拍、搜、买。
8. 内容玩法 1：官方内容/TVC/话题。
9. 内容玩法 2：达人矩阵/挑战赛/UGC。
10. 转化玩法：直播、搜索、货架、主会场。
11. 品牌共创入口：按品类/场景拆角色。
12. 核心资源矩阵：站内资源、达人、直播、PR、线下。
13. 合作权益包：冠名、行业合作、品类伙伴等。
14. Roadmap：预热、爆发、长尾。
15. 预估产出/案例参考。
16. 招商席位和下一步。
17. Thanks。

## 视觉学习方向

- 大事件招商常用强封面、大片感背景、大数字页、资源矩阵页。
- 平台型招商方案标题通常直接下判断，页面信息密度中高。
- IP 型方案要有统一语汇，例如“风”“源”“心跳”，并让它贯穿标题、玩法、视觉符号。
- 权益/资源页必须克制清晰，不能为了潮流感牺牲可读性。
- 品牌招商需要保留“活动感”和“销售可谈性”的平衡：前半段造势，后半段落到资源和转化。

## 飞书文档排版与图文穿插学习

从招商手册型样本里，还能抽象出一套比“章节结构”更细的排版经验：

### 1. 飞书文档不是纯文字版 PPT，而是可扫读的招商界面

- 开头往往不是直接进入正文，而是先给一屏式摘要，让人几十秒内判断值不值得继续看。
- 正文里会反复使用高亮块、短列表、分组字段，而不是大段说明文。
- 章节内部强调“先判断、后解释、再给图证”，而不是“先解释半天，最后补一句结论”。

### 2. 分栏是高频排版骨架，不只是装饰

标杆文档会用分栏承接：

- 左侧写项目判断，右侧写品牌价值。
- 左侧写玩法说明，右侧放截图或示意图。
- 左侧列资源权益，右侧放点位图、会场图、页面截图。
- 左右并列对照不同阶段、不同合作角色、不同资源包。

有效分栏的共同点：

- 两栏之间有明确分工，不是简单均分文字。
- 同一栏中的信息密度相近，避免严重失衡。
- 分栏用于缩短理解路径，让品牌横向比较，而不是一直向下翻。

### 3. 折叠面板收纳补充信息，保护主阅读链路

适合折叠的内容包括：

- 详细执行规则
- 指标口径解释
- 可选资源 / by case 资源
- 过往案例补充
- 素材提报与审核说明

核心信息不能折叠：项目价值、合作方式、核心权益、关键席位必须直接展开。

### 4. 原版 PPT / 视觉稿要精准嵌入对应章节

高质量文档经常把原始 PPT 页面、主视觉、会场图、玩法页截图直接穿插到正文里：

- 主题章节配 KV / slogan 页面。
- 玩法章节配对应玩法截图。
- 权益章节配资源示意图。
- Roadmap 章节配节点物料或节奏页。

核心不是“多放图”，而是让图片和当前文字形成一一对应。

### 5. 图片必须证明某个判断

文档图片通常承担以下作用：

- 建立项目气质
- 解释复杂玩法
- 证明资源真实性
- 帮助销售与客户快速对齐认知

如果一张图不能回答“它在证明什么”，那它大概率只是装饰。

### 6. 版面节奏优于普通 Word 式长文

成熟样本会避免：

- 连续多屏纯文字
- 连续多张无说明截图
- 所有信息都用同一层级标题铺开
- 重要信息和补充备注混在一起

更常见的做法是：

- 用高亮块建立第一印象。
- 用分栏压缩理解路径。
- 用折叠面板收纳补充细节。
- 用截图和图注做章节级视觉锚点。
- 用表格承接可复制的权益和资源信息。
